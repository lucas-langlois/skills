# Author brief

Pre-fill from supplied materials; accept rough notes. Ask only for what changes the next useful step.

- Document and editing mode:
- Audience, journal/article type or report template:
- Main message in the scientist's own words:
- Actual scientific or management question:
- Principal findings and source files/tables:
- Author interpretation and strongest limitation:
- Intended practical implication or recommendation:
- Voice sample or paragraphs to preserve:
- Final methods/analysis files and unresolved discrepancies:
- Figures/tables and source data:
- Citation manager, output style and reference records:
- Confirmed author/funder/permission/declaration statements:

First round: normally no more than three questions based on actual gaps. Keep formatting and proofreading moving.
